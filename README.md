# Инвентаризация и мониторинг рабочей станции

Лабораторная работа № 4, вариант 10. Для работы нужны Python 3.12 или новее и библиотека psutil.

| Файл | Назначение |
| --- | --- |
| `inventory.py` | Собирает данные о системе, CPU, памяти, дисках и IPv4-интерфейсах. Записывает паспорт и рекомендации в JSON. |
| `monitor.py` | Измеряет CPU, RAM, заполненность системного раздела (корня домашней папки) и занятый swap. Записывает 15 строк в CSV с интервалом 4 с и выводит минимум, среднее и максимум. |
| `passport_demo.json` | Пример полного формата паспорта. Имя узла, время, имена интерфейсов и сетевые реквизиты заменены учебными значениями. |
| `monitor_log.csv` | Создаётся при запуске. Поле `alert` содержит все пороги, достигнутые в одном замере. |

## Запуск

Из каталога со скриптами:

```sh
python -m venv .venv
```

В Windows PowerShell активируйте окружение командой `.\.venv\Scripts\Activate.ps1`. В Linux или macOS выполните `source .venv/bin/activate`.

```sh
python -m pip install psutil
python inventory.py
python monitor.py
```

Личный паспорт появится в файле `passport_<имя компьютера>.json`. Он исключён из Git. Каждый запуск монитора создаёт журнал заново. Пороги CPU, RAM и диска равны 80, 90 и 90 % соответственно. DISK показывает долю занятого пространства. Для значений в ГБ используется делитель 1024³.

## Пример формата строки CSV

Учебный пример с условными значениями:

```csv
time,cpu,ram,disk,swap_gb,alert
10:00:04,12.5,90.0,51.0,0.500,RAM = 90.0% (порог 90%)
```
